# Programa del Ejer-Arreglos.py

Este programa sirve para registrar las ventas de tres departamentos: Ropa, Deportes y Juguetería durante los 12 meses del año (Yo entendi q debian ser los 12 meses no solo los que puso de ejemplo en la actividad) Al iniciar, todas las ventas aparecen en 0 porque todavía no se ha registrado ninguna.

El programa tiene un menú con diferentes opciones. La primera opción es INSERTAR VENTA, donde se elige el mes, el departamento y se escribe cuánto se vendió. La segunda opción es BUSCAR UNA VENTA, donde se selecciona un mes y un departamento para saber cuánto se vendió en ese lugar. La tercera opción es ELIMINAR UNA VENTA, que sirve para quitar una venta registrada y volverla a poner en 0. La cuarta opción es MOSTRAR TODAS LAS VENTAS, donde se puede ver una tabla con los 12 meses y las ventas de cada departamento. Por último, la opción 5 sirve para salir del programa.

El método `insertar_venta()` sirve para agregar una venta al programa. Primero pide el mes, después el departamento y finalmente el monto de la venta. El método `buscar_venta()` sirve para consultar una venta que ya se haya registrado, indicando el mes y el departamento. El método `eliminar_venta()` sirve para borrar una venta y cambiar su valor a 0. El método `mostrar_ventas()` sirve para mostrar todas las ventas registradas en una tabla.

En general, el programa permite llevar un registro sencillo de las ventas de Ropa, Deportes y Juguetería durante todo el año.
